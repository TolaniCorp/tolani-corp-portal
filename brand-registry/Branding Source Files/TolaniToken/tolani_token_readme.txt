# Tolani Token (TOL) 🚀

**The Official Token Powering the Tolani Corp Ecosystem**

---

## 📖 Overview

**Tolani Token (TOL)** is a utility token designed to facilitate seamless transactions, governance, and incentivization within the **Tolani Corp** ecosystem, including:

- **Decentralized Autonomous Organization (DAO) Governance**
- **HVAC and Construction Project Funding**
- **Environmental, Social, and Governance (ESG) Initiatives**
- **Workforce and Training Incentives** via Tolani Labs
- **Tokenized Payroll and Escrow Management**

## 🌟 Key Features

- **Utility Token**: Explicitly designed to comply with global regulatory standards, including Wyoming DAO LLC regulations.
- **Transparent Governance**: Managed by a decentralized community through platforms like Snapshot and Gnosis Safe.
- **Project Integration**: Powers real-world construction, HVAC services, training, and workforce incentives.
- **ESG-Driven**: Blockchain-based ESG tracking, reporting, and incentivization.

## 🛠 Installation & Setup

Clone and install dependencies:

```bash
git clone https://github.com/tolanicorp/TolaniToken.git
cd TolaniToken
npm install
```

Run local development environment:

```bash
npm run dev
```

Compile and deploy smart contracts:

```bash
npm run contracts:compile
npm run contracts:deploy
```
