Operations & Security Protocols

Release Guardrails

  • Automated Testing: Full Vitest suite required for all PRs.
  • Human-in-the-Loop: Mandatory peer review for agent logic changes.
  • Secret Hygiene: No keys in code; environment-only injection.
  • Rollback Readiness: 1-click revert for all deployments.

Incident Response

  • P0/P1 Triage: Immediate action required; no delay.
  • Auth-Only Scanning: NATT agents scan only authorized targets.
  • Audit Logging: Every agent action is tracked and immutable.
  • Secret Rotation: Mandatory rotation after any suspected breach.
